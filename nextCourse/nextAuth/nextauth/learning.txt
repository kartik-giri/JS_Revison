getServerSession() reads the cookie from the incoming request and returns the current logged in user's session data — all on the server side.

What it does step by step
User visits your page
      ↓
Browser automatically sends the auth cookie with the request
      ↓
getServerSession() reads that cookie
      ↓
Decrypts and verifies it using your NEXTAUTH_SECRET
      ↓
Returns the session object if valid
Returns null if not logged in
