11. SSG
What even is a "static" site?
Imagine you have a file hello.html sitting on your computer. You double click it — it opens in the browser instantly. No server needed, no database, no code running. That's a static site at its most basic.
Static = the files are already made before anyone visits.

Compare that to dynamic:
Static:  User visits → Server sends pre-built HTML file → Done
Dynamic: User visits → Server runs code → queries DB → builds HTML → sends it → Done

The problem static sites solve
Think about a blog with 1000 posts. With a dynamic site (like a normal Next.js app):
Every single visitor to /blog/my-post does this:
1. Request hits your server
2. Server runs JavaScript
3. Server calls your database → "give me post where slug = my-post"
4. Database responds
5. Server builds the HTML
6. Sends to user

1000 visitors = steps 1-6 happen 1000 times
With SSG (Static Site Generation):
At BUILD TIME (once, before anyone visits):
1. Next.js runs your code
2. Fetches all posts from DB
3. Builds HTML files for every post
4. Saves them as .html files

Now at runtime:
1000 visitors = just sends the pre-built file 1000 times
No DB calls. No server code. Just files.

The mental model is simple — use SSG whenever the page content is the same for every user and doesn't change every minute. 
Blogs, documentation, landing pages, product listings — all perfect candidates for SSG.

## TO FORCE NEXT JS TO GENERATE SSG:-
1. generateStaticParams — for dynamic routes
This is the main way. If you have [slug], Next.js won't SSG it unless you tell it which slugs to build:
tsx// app/blog/[slug]/page.tsx

export async function generateStaticParams() {
  const res = await fetch("https://api.example.com/posts");
  const posts = await res.json();

  return posts.map((post) => ({ slug: post.slug }));
}

const BlogPost = async ({ params }) => {
  const { slug } = await (params);
  const res = await fetch(`https://api.example.com/posts/${slug}`);
  const post = await res.json();
  return <h1>{post.title}</h1>;
};

export default BlogPost;

2. dynamic = "force-static" — force any page to be static
Even if Next.js thinks a page should be dynamic, this forces it to SSG:
tsx// app/about/page.tsx

export const dynamic = "force-static";  // ← forces SSG

const AboutPage = () => {
  return <h1>About Us</h1>;
};

export default AboutPage;
