//Canvas
Canvas is basically a blank whiteboard in HTML that you can draw on using JavaScript.

HTML gives you the whiteboard:
html<canvas id="myCanvas" width="800" height="600"></canvas>
JavaScript gives you the pen:
javascriptconst canvas = document.getElementById("myCanvas")
const ctx = canvas.getContext("2d")  // ctx = your pen/brush

ctx is everything — it has all drawing methods:
javascript// Draw a rectangle
ctx.fillRect(x, y, width, height)

// Draw a line
ctx.beginPath()
ctx.moveTo(x1, y1)   // pick up pen, move to start
ctx.lineTo(x2, y2)   // draw line to end
ctx.stroke()          // actually render it

// Draw a circle
ctx.beginPath()
ctx.arc(x, y, radius, 0, Math.PI * 2)
ctx.stroke()

// Write text
ctx.fillText("hello", x, y)

Think of it like physical drawing:
ctx.beginPath()   →  pick up pen from paper
ctx.moveTo()      →  place pen at starting point
ctx.lineTo()      →  drag pen to draw line
ctx.stroke()      →  press pen down (makes it visible)
ctx.fill()        →  fill shape with color


PANNING
1. Panning is the act of moving window across the map.
2. pan x means how many pixels shapes will render on x a-axis.
3. 2. pan y means how many pixels shapes will render on y a-axis.
4. viewportTransform — tracks where your viewport is:
const viewportTransform = {
    x: 0,      // how much we've panned horizontally
    y: 0,      // how much we've panned vertically
    scale: 1   // zoom level
}

5.updatePanning — how pan amount is calculated:
javascriptconst updatePanning = (e) => {
    const localX = e.clientX   // current mouse position
    const localY = e.clientY

    // how far did mouse move since last frame?
    viewportTransform.x += localX - previousX
    viewportTransform.y += localY - previousY
    //                      ↑
    //              delta = difference between
    //              current and previous position

    previousX = localX  // save for next frame
    previousY = localY
}
Example:
previousX = 100  (mouse was here)
localX    = 120  (mouse moved here)

delta = 120 - 100 = 20px moved right
viewportTransform.x += 20  ← pan right by 20px

Next frame:
previousX = 120
localX    = 115  (mouse moved left)

delta = 115 - 120 = -5px
viewportTransform.x += -5  ← pan left by 5px

In panning means winfdow is moving across the map.
means cordinates are changed from 0,0 to lets say 100,100
means viewport is moved to 100 px right and 100 px down.
which means the previous shapes which renders on (10,10) becomes rndering on (110,110);

What you SEE:          What actually happens:
─────────────          ──────────────────────
shapes moving →        coordinate system moving
                       shapes staying still
                       but appearing in different
                       screen positions
