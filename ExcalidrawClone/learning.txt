//Canvas
Canvas is basically a blank whiteboard in HTML that you can draw on using JavaScript.

HTML gives you the whiteboard:
html<canvas id="myCanvas" width="800" height="600"></canvas>
JavaScript gives you the pen:
javascriptconst canvas = document.getElementById("myCanvas")
const ctx = canvas.getContext("2d")  // ctx = your pen/brush

ctx is everything — it has all drawing methods:
javascript// Draw a rectangle
ctx.fillRect(x, y, width, height)

// Draw a line
ctx.beginPath()
ctx.moveTo(x1, y1)   // pick up pen, move to start
ctx.lineTo(x2, y2)   // draw line to end
ctx.stroke()          // actually render it

// Draw a circle
ctx.beginPath()
ctx.arc(x, y, radius, 0, Math.PI * 2)
ctx.stroke()

// Write text
ctx.fillText("hello", x, y)

Think of it like physical drawing:
ctx.beginPath()   →  pick up pen from paper
ctx.moveTo()      →  place pen at starting point
ctx.lineTo()      →  drag pen to draw line
ctx.stroke()      →  press pen down (makes it visible)
ctx.fill()        →  fill shape with color
